# Video Assets for Creative Portfolio

You can place your reel video files (MP4 or WebM) in this directory to display them directly in the creative portfolio.

## Recommended File Names
- `skinny-jeans.mp4` — The Skinny Jeans Transformation (Project 01, 549K views)
- `hal-jordan.mp4` — Hal Jordan Inspired Fashion (Project 02, ~50K views)
- `boost-chair.mp4` — Boost Lifestyle Ergonomic Chair Campaign
- `nestle.mp4` — Nestlé Pure Life Day-in-the-Life Integration
- `amd-fragrances.mp4` — AMD Fragrances Dolmen Mall Review

## Format Recommendations
- Aspect ratio: 9:16 (vertical reel format, e.g. 1080x1920 or 720x1280)
- Codec: H.264 / AAC
- Container: MP4
- Files will automatically be loaded with responsive fallback to Instagram links.
